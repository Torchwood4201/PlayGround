1P GAME MODE

At the Game Mode Select screen, select 1P GAME MODE and press the Start
button. The Player Select screen will then appear. Select any one of 14
different characters. Press any button (L, R, A, B, X, or Y button) to set your
selection.

Press the Y button to select COIN-UP original color.

The Mode Select screen will then appear. Choose either Normal mode or
Survival mode. Press any button to set your selection. The game will then
begin.

A second player can join the action at any time. Simply press the Start button
on the 2P controller to start playing. The winner of the match can then switch
back to a 1P game and continue playing.
