# Vista maps (self-hosted)

`kanto-vista.webp` is stitched from a fan-made Kanto overview tile grid
(18x19 tiles, `gen1_kanto_small_RRR_CCC.webp`) and `kanto-vista.json` holds a
generated 36x38 collision/encounter grid derived from it (1 ground, 49 grass,
77 wall, 29 water). Tiles were fetched once for offline use; credit the
original tile artist/site in any public remix.
