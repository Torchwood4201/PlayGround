# Plan: Cycles ≠ Dialog / Brain = Beta4 Backend (realignment)

## User correction (binding)
- **Cognitive cycles are not dialog.** `CognitiveOS.runCycle` (`src/core/controller.ts:90-230`,
  driven by `src/components/CognitiveInterface.tsx`) is autonomous background cognition.
  Dialog (`src/App.tsx handleMessage` → `ConversationInterface.tsx` → `answerComposer.ts`)
  is a separate path. Neither invokes the other today — but they share two data channels
  that pollute cycles with chat chatter (see §1).
- **The positronic brain is a backend for Beta4.** `PositronicBrain`
  (`src/core/PositronicBrain.ts`, in-RAM only) must become the private, persisted substrate
  of the `Beta4` person entity (`src/core/Beta4.ts`), behind person-level verbs only.
- Follow the realignment guide: perception / workingMemory / longTermMemory / reasoning /
  `controller.ts`, `components` split, `shared/`, `types/` contracts, event bus, `feedback.ts`.

## 1. Decouple cycle ↔ dialog (FIRST — correctness)
Coupling (verified): (a) LOOSE — chat writes `CONVERSATION Q:|A:` records (`App.tsx:223`)
retrieved unfiltered by cycle planning query (`controller.ts:140-143`); (b) TIGHT — chat
writes `WORKING: CHAT Q:` notes (`App.tsx:224-228` → `controller.ts:285`) read by
`planningPrompt slice(-5)` (`controller.ts:145`): every chat turn shifts the next cycle prompt.
EventBus has 0 subscribers; `run()` (`controller.ts:242`) is dead.

- **CREATE `src/types/memory.ts`**: `MemoryNamespace`
  (`dialog|knowledge|observation|task|experience|system`), `CYCLE_RETRIEVAL_ALLOWLIST`
  (`knowledge,observation,task,experience` — excludes `dialog`), `HistoryNote`
  (`{text,visibility:ephemeral|cycle-visible,origin:dialog|cycle|system,ts}`).
- **`src/core/longTermMemory/index.ts`** (additive): optional `namespace/marker` on records;
  `inferNamespace()` prefix fallback (`CONVERSATION→dialog`, `DOCUMENT/SEED→knowledge`,
  `OBSERVATION→observation`); `queryScored(q, {allowlist?})` filter args (default off);
  `queryCycle(q,k)` = allowlisted query. No re-embed/re-ingest. `query()` unchanged.
- **`src/core/controller.ts`**: split `history` into `ephemeralBuffer` (dialog turns) +
  `committedHistory` (cycle-visible); `noteEphemeral()` / `promoteToCycle(reason)` /
  `getCycleVisibleHistory(n)`; planning prompt (`:145`) reads committed only; planning
  query (`:140-143`) uses `queryCycle`. Keep `getHistory()` read-compat for UI.
- **`src/App.tsx`**: `handleMessage` writes `CONVERSATION` with `namespace:'dialog'` and
  `noteEphemeral(...,'dialog')` (was `rememberWorking`); seed/ingest notes → ephemeral
  `system/task`, never auto-promoted. `answerComposer.ts` untouched (thresholds/filters stay).
- **`src/components/CognitiveInterface.tsx`** (additive): "Promote to cycle" button —
  the ONLY dialog→cycle bridge, manual + logged. Seed/ingest promote a summary, never raw chat.
- Contract (also as code comment in `src/types/contracts.ts`): dialog writes
  `dialog`-namespaced LTM + ephemeral notes and reads `knowledge` only; cycles write/read
  `observation/task/experience` + committed history; dialog never calls `runCycle`, cycles
  never call `onMessage`.

## 2. Brain as Beta4's persisted backend (SECOND)
Today: Beta4 hot path (`perceive/thinkAndAct`, `Beta4.ts:35-48`) is 100% brain; `modelHub`
member is never referenced; `cognitiveOS/positronicCore` only in cold `getMemories/introspect/getState`;
brain is privately `new`'d (`Beta4.ts:28`, no injection slot), in-RAM caps 200/10, zero storage.

- **CREATE `src/types/brain.ts`**: `BrainSnapshot {version:1, memories[{content,namespace,ts,salience}],
  workingMemory[{content,ts}], goal, emotion{valence,arousal,label}, updatedAt}`.
- **`src/core/PositronicBrain.ts`** (additive, keep method names): `attachProvider()` /
  `loadSnapshot()` (corrupt→empty+log, never throws boot) / `getSnapshot()` (deep-frozen copy) /
  `restoreSnapshot()` (clamp caps) / debounced `scheduleAutosave()` called from every mutator;
  key `positronic.brain.v1` (same `StorageProvider` interface as Core/VectorMemory).
- **`src/core/Beta4.ts`**: `brain` stays privately constructed (or optionally injected, default-construct
  for compat); expose ONLY `getBrainSnapshot()/restoreBrain()` (no live accessor) + existing
  verbs `perceive/thinkAndAct/run/setGoal/getState/getMemories/introspect`; add `async boot()`
  (`attachProvider` + `loadSnapshot`); division of labor in header comment: brain = planner/memory/affect
  substrate (owns persistence); `cognitiveOS` = LOOP-ONLY autonomous loop Beta4 may optionally drive
  via `tick()` but hot path must not call it; `modelHub` = generation service via
  `brain.attachGenerator(modelHub)` with canned-string fallback — if delegation >L, REMOVE the member
  with a reason comment instead (no decorative members); `positronicCore` decision deferred to §3.
- **`src/App.tsx` boot**: call `beta4.boot()` alongside existing restores.
