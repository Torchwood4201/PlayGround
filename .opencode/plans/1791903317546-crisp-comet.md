# Plan: Grounded Answers — make the AI reply from its own memory

## Problem
Chat answers are canned/random and ignore everything the app stores. `handleMessage`
(`src/App.tsx:189-220`) picks a random template from `UnifiedModelHub.generateText`
or `PositronicCore.processThought`. The 84-record seed knowledge base, uploaded
document chunks, and prior turns are write-only — nothing in the chat path calls
`VectorMemory.query()`.

## Approach
Two modes, decided per question (no LLM, no new deps):
- **Strong match → direct answer.** The retrieved fact *replaces* the template:
  answer leads with the cited excerpt(s), no random filler.
- **Weak/no match → template + cited block** (previous fallback behavior).
Plus the agreed scope expansion: remove the dead PositronicBrain demo code,
plug Beta4 into the shared instances, and make cognitive cycles runnable hands-free.

## Edge cases
Marker leak (`SEEDED:` matches queries) → filtered. Empty/corrupt store →
ungrounded fallback, chat still works. Quota failure → caught, reply unaffected.
Long records → 280-char excerpts. Hub-not-ready branch → same compose path.
