# Plan: Merge Oscillator XY-Scope + Piano Theory + Drum Machine into Liquid Synth host

## 1. Intent & assumption (needs user confirmation)
- User posted four URLs with no explicit instruction:
  - A: https://github.com/EvanWestermann/Oscillator (`Oscillator.git`) — vanilla single-file audiovisual synth (dual sine/saw 10–880Hz, hard-panned L/R, waveshaper + fixed lowpass, Canvas 2D XY Lissajous / WAVE RGB scope, CRT styling). No build, no keyboard/MIDI/ADSR.
  - B: https://github.com/GuoChen018/piano-app (`piano-app.git`) — React 19 + Vite 6 + Tone.js Salamander-sampler teaching piano (C3–B5, scale/chord theory, progression builder, MIDI export, 2 demo songs). Monolith `src/components/Piano.jsx` (~1100 lines) + zero-dep `src/utils/midiExport.js`.
  - C: https://github.com/Revisto/drum-machine (`.git`) — NATIVE Linux desktop app (Python + GTK4 + libadwaita, `pygame.mixer` realtime, `numpy` + `ffmpeg` export, `mido` MIDI), 10 sample-based `.wav` voices (99Sounds), 16-step infinite-page grid, BPM/volume only, GPL-3.0. Product/pattern reference only — nothing to port verbatim (imperative GTK, `time.sleep` thread scheduler, GPL copyleft → clean-room reimplement).
  - D: https://googlechromelabs.github.io/web-audio-samples/demos/shiny-drum-machine/ (source: GoogleChromeLabs/web-audio-samples `src/demos/shiny-drum-machine/`) — vanilla JS ES modules + raw Web Audio, sample-based 6 voices (Kick/Snare/HiHat/Tom1-3) × 16 steps with 3-state velocity, 15 kits + 20 convolver IRs, tempo 50–180, swing, per-voice pitch. - Assumed intent: enrich the PlayGround Liquid Synth host (React 19 + Vite 6 + raw Web Audio, `App.tsx`, `hooks/useAudioOscillator.ts`, `components/PianoKeyboard.tsx`, `utils/notes.ts`) with (A) an XY vector-scope visualizer panel, (B) a music-theory panel (scale highlight + chord builder + progression MIDI export), and (C/D) a drum-machine panel (6-track × 16-step sequencer with synthesized drums + lookahead scheduler + MIDI/JSON pattern save-load) — keeping the host engine, build (`npm run build` → `dist/`), and `bash start.sh` preview green.
- If the user instead wants a full engine swap, wholesale imports, or separate demo pages, say so — alternatives are listed in §6 and rejected for now.

## 6. Alternatives rejected (say the word to switch)
- Full swap to A's engine: loses 4-voice polyphony, ADSR, FX, recorder, MIDI — visualizer recipe only.

- Tone `Sampler` as default voice / vendored ChromeLabs kits / hotlinked 99Sounds WAVs: licensing (undocumented / royalty-free≠MIT) + CORS/offline risk — synthesized drums + optional user upload only.
- Porting C's Python/GTK/`pygame` audio path or D's chained-`setTimeout` scheduler verbatim: drift + lifecycle + copyleft problems — clean-room lookahead scheduler in Web Audio.
