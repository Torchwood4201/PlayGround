## 1. Triage (static findings, severity-ranked)
**Confirmed real (read in current code):**
- **D1 — Bounce has no rebound.** `main.ts:1168` zeroes `axeVel`, then `resolveStick → deflect(hitPoint)` (`1118+`) computes rebound from the zeroed vector → bounce hangs at `(±1,0,0)` instead of rebounding. Trigger: ~28% of face hits. Fix: snapshot velocity before zeroing, pass into `deflect`.
- **D2 — Killshot log always lies.** `main.ts:1059` clears `calledKillshot` before the `1061` log ternary → always prints `called-miss`, even on 8-pt hits. Scoring (`1048`) correct. Fix: capture result string before clearing.
- **D3 — Digit1/2/3 aborts live throws.** `main.ts:1252-1254` has no phase/axeState guard; `equipFrame → resetAxeToHand → IDLE` voids in-flight/stuck axes with no miss, skipping recall/end rules. Fix: ignore unless `phase==='play' && axeState==='IDLE'` (menu minis already safe).
- **D4 — KeyR during CHARGING leaks charge state.** `main.ts:1260` flips to `RECALLING` without clearing `charging/charge/overcharge`; recalled-to-IDLE axe renders charged pose and `currentPower()`/trajectory use stale charge. Fix: clear charge fields on R-abort (or route through `resetAxeToHand` + explicit recall accounting).
- **D5 — Esc/lock-loss while CHARGING forces a throw.** `main.ts:1241-1245` calls `releaseAxe()` (succeeds, burns an axe) then pauses. Intent is cancel. Fix: cancel charge without throwing (`charging=false`, back to IDLE), then pause.
- **D6 — KeyQ toggleable mid-flight.** `main.ts:1256-1258` no state guard; flipping after release changes scoring outcome. Fix: only allow when `axeState==='IDLE' || 'CHARGING'` (latch at release).
**Needs runtime evidence (could not decide statically):**
- **D7 — Timer firing mid-flight scores behind resolve screen** (`1332-1338` vs `1340-1346`): code clearly keeps stepping in resolve; need headed repro (release <1s before timeout) to confirm visible desync. Fix if confirmed: freeze axe + defer resolve until axe back to IDLE (or resolve immediately and void in-flight throw — designer call).
- **D8 — Called-killshot miss leaves axe visually STUCK while counting a miss** (`1166-1170` pins position before `resolveStick` knows the outcome). Likely real; confirm headed, fix by deflecting/repositioning on called-miss.
- **D9 — Motion ramp unbounded in endless** (`417-419`: `1+0.2*floor(elapsed/30)`, endless has `time=null`): at 10 min boards slide 5× speed. Confirm feel headed; cap ramp (e.g. max 2×) if approved.
- **By design, do not "fix":** dead `stickThreshold`/`grazeExtraSpeed` (impact speeds 15–32 m/s always pass — rebalance out of scope; instead add `IMPACT_SPEED` debug log so a human can retune later); first-click-eats-lock (browser gesture requirement, document it); vector-lock persistence semantics (designer call).
**False alarm / minor:** stand legs float ~0.6 m (visual only); trajectory cuts at z=-26 vs miss bound -38 (cosmetic); `onNode && points<1` branch dead but harmless; frame-rack hit spheres overlap (nearest-sort mitigates; verify headed).

## 3. Playthrough test plan
### Tier A — headless sync (CI-assertable)
Base: `chromium --headless=new --no-sandbox --enable-unsafe-swiftshader --use-gl=angle --use-angle=swiftshader --virtual-time-budget=15000 --dump-dom 'URL' | grep -o '<title>.*</title>'`, plus console-log counts.
- `?selftest=1` → `SELFTEST level=precision … throws=10 hits=10 phase=resolve`, 10 `OUTCOMES=STUCK@…`, 10× `THROW_RESOLVED`, 1× `LEVEL COMPLETE`.
- `?selftest=classic|movers|spinners|blitz|gauntlet|endless` → `throws=6 phase=play`, zero `Uncaught`, `THROW_RESOLVED` count == 6 (any mix of stick/bounce/miss proves path coverage incl. movers sliding-lead misses).
- `?selftest=bogus` → after F8 warns and stays menu (today: silent `level=classic` — assert the NEW behavior).
- Console assertion: every run has zero `Uncaught`; `THROW_RESOLVED.result` never `called-miss` on a non-killshot run.
### Tier B — headless render (spawn-state screenshots, ~4 frames each)
- `/` → 7 totems + frame minis + rails, non-black.
- `?autostart=classic` → hand axe, dashed trajectory, centered crosshair, scoreboard, lit rack.
- `?autostart=blitz` → no gold halo at elapsed≈0 (spawnAt≥5), timer digits visible.
- `?autostart=endless` → exactly 3 red rack pips. `?autostart=precision` → no timer digits.
- Failure signatures: black screen (WebGL fail), missing totems (menu regression), digit soup (seven-seg regression).
### Tier C — real-browser human script (pointer lock + gesture required)
Setup: desktop Chrome, `:3002`, DevTools console open, `localStorage` cleared. One pass per level `classic→precision→movers→spinners→blitz→gauntlet→endless`:
1. **Menu:** hover each totem → crosshair gold + 1.35×; click → correct arena+resource digits; count clicks after lock-loss (documents D-doc behavior).
2. **Throws:** tap / full-hold / >1s overcharge (red arc + jitter + spray); record 3 `IMPACT_SPEED` values per frame (F8).
3. **Tiers:** center `standard` → white perfect burst + shake; `spinners` side-on → red bounce + rebound (F1); 3 perfects → gold orbiters + lock; anchor graze → −2 (F-wiring).
4. **Killshot:** Q in IDLE → 10 Hz nodes + red arc; node hit → +8×mul + arpeggio, log `killshot` (F2); off-node → miss + rebound (F7); Q mid-flight → ignored (F6).
5. **Frames/pause/recall:** `1/2/3` mid-flight ignored (F3); menu minis equip + spin; `P`/Esc behavior incl. Esc-mid-charge cancel (F5); R mid-charge/stuck (F4).
6. **Endings:** timer-expiry mid-flight (F7), precision 10-axe, endless 3-miss → final+best digits, retry/menu totems, Enter/M shortcuts; corrupt `axevector-best-classic` → best shows 0 (F8).
7. **Touch/audio/tab:** tap-select vs drag-aim thresholds (250 ms/4 px); L/R pan by target side; lock-loss on tab-switch cancels charge.
- Log every failure as: `ID | level+frame | 3-step repro | expected 3D+console | actual screenshot+log quote | severity | suspect lines | status`.

## 4. Non-goals
No scoring rebalance (thresholds/bonuses/multipliers unchanged); no new levels/copy/visual redesign; zero-DOM rule holds (diagnostics to console/title only); no rAF-architecture rewrite; vector-lock/ramp-cap policy needs designer sign-off (instrument first).

## 5. Risks & exit criteria
- Risks: rAF starvation (fallback: sync selftest + human Tier C); pointer-lock untestable headless (manual click-counts only); selftest always center-aims (movers misses are path-proof, not quality-proof); wall-clock recall vs pause (assert end-states, not delays).
- Exit: `tsc` clean, `build` clean, all Tier-A patterns match with log counts exact, Tier-B screenshots non-black, Tier-C script complete with defect log triaged, no balance constants changed.
