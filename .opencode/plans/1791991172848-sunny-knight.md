# AXE//VECTOR — Full Render Progression Plan (wireframe → solid → textured → lit → post)

## 0. Context
- User demands the full chain on the live game: solid/shaded surfaces, procedural textures + PBR, lights/shadows, post-processing. All procedural/canvas-generated (offline-capable, zero external assets). Zero-DOM-UI holds. No gameplay/physics/scoring/layout/balance changes.
- Verified baseline: three 0.170.0 installed; `three/addons` EffectComposer/RenderPass/UnrealBloomPass/OutputPass/RoomEnvironment all present on disk; current code is lines-only (sole Mesh is an invisible raycast proxy); no lights/textures/shadows anywhere; r170 = physical light units, sRGB output default, composer REQUIRES OutputPass last.
- Draw-call budget (<150) is the binding constraint: classic ≈115, realistic gauntlet ≈151 (already at cap). 1:1 solid counterparts would hit ~230–300. The plan solves this via textured single-disc targets (6 ring loops → 1 disc+texture per board) + InstancedMesh for pips/orbiters.
- Rigging: N/A — zero skinned meshes; everything is rigid bodies + pivot-Group animation. Not implemented, by design.
- Headless SwiftShader renders ~4 rAF frames: composer/bloom/shadows are gated OFF under CI (`?selftest`/`?audit`/SwiftShader/reduced-motion); `?bloom=1` forces ON for human GPU review.

## 1. Staged rollout (ship + verify each stage independently)
- **S1 — Solid backing meshes (heroes only).** `Mesh` using each object's existing base geometry (axe Box+Cone, totems, minis, crystals, kill nodes primary-board-only, prisms, icons) with unlit dark `MeshBasicMaterial` under kept wireframe overlays (`depthWrite` on solids, lines `depthWrite:false` + renderOrder). Rack pips → `InstancedMesh` (10→1), orbiters → `InstancedMesh` (5→1). New `src/render/solids.ts` helpers. Flag: `?solid=0`. Expected: classic ~121, gauntlet ~157 (known-over, S3 fixes).
- **S2 — PBR + lights.** All S1 Basic → `MeshStandardMaterial` (axe handle rough .8/metal .1; head rough .35/metal .9; neon bits emissive 1.2–2.2 in line colors; pulse code migrates opacity→emissiveIntensity). Rig: HemisphereLight 0.6 + DirectionalLight 2.5 key with 2048 PCFSoft shadows (±18 ortho box) + cyan/rose PointLights (25/18, decay 2) + RoomEnvironment IBL via PMREM (`new RoomEnvironment()` — NO renderer arg in r170) at 0.35 intensity. Floor ShadowMaterial catcher plane. ToneMapping stays OFF until S4. Flags: `?lit=0`, `?shadows=0`, `?env=0`. New `src/render/lighting.ts` (+`pbr.ts` if params grow).
- **S3 — Procedural textures + draw-call rescue.** New `src/render/textures.ts`: CanvasTexture builders (target face = zone rings+grain per SCORING_ZONES, floor grid, wall panels, handle wrap, brushed head roughness/bump); albedo gets `SRGBColorSpace`, data maps stay linear; POT sizes, RepeatWrapping, anisotropy ≤ max. Single textured `CircleGeometry(1.35,72)` disc per board REPLACES the 6 ring LineLoops (keep 1 bullseye overlay or EI pulse). Result: classic ~98, gauntlet ~132–145 — back under cap. Flags: `?tex=0`, `?disc=lines`.
- **S4 — Composer + bloom.** New `src/render/composer.ts`: RenderPass → UnrealBloomPass(threshold 0.85, strength 0.65, radius 0.4) → OutputPass (LAST) + ACESFilmic exposure 1.05; resize/pixelRatio plumbing; auto-off under SwiftShader/reduced-motion/CI with console reason; `?bloom=0|1` override.
- **Deliberately kept as lines forever:** seven-seg small/resource digits (big scoreboard/timer/final/best become single-canvas texture planes each — 15 draws → 4, redrawn only on value change), trajectory dashes, trail, charge arc, bursts, stands, dial/cross rings.

## 2. Per-stage verification (executor)
- `npx tsc --noEmit` + `npm run build` each stage.
- Behavior invariants: `?selftest` / `?selftest=gauntlet` / `?audit` titles byte-identical to pre-change (visual-only; any score/throws/audit delta = FAIL).
- Screenshots: S1 dark solids behind lines, nothing removed; S2 shading moves on totem rotate + floor shadows, lines still brightest; S3 ring texture visible, disc pulses on aim; S4 (`?bloom=1`, real GPU) halos with black blacks, `?bloom=0` pixel-matches S3.
- Perf: add `?stats=1` console reporter (renderer.info calls/tris + fps every 60 frames; no DOM overlay). Human approves 60fps + calls <150 on gauntlet. SwiftShader runs are correctness-only.
- Full revert = all flags off → pixel-identical legacy wireframe.

## 3. Non-goals
No rigging/skeletons; no external assets (fonts/models/HDR); no gameplay/physics/scoring/layout/constant changes; bloom/exposure values are human-approval tuning, not CI assertions.

## 4. Risks
Gauntlet still >150 after S3 → kill-node solids to primary-only, prisms lines-only (flags bisect). SwiftShader CI flakes → CI runs titles with bloom/shadows implicitly off. Bloom washout → raise threshold before touching emissive. Transparent sorting → solids depthWrite+polygonOffset, lines renderOrder 10. Low-GPU fill-rate → `?perf=low` caps composer pixelRatio at 1.5.

# AXE//VECTOR — Debugging + Full Playthrough Testing Plan (prior, retained)

## 0. Context (read this first)
- Game: `src/main.ts` (~1489 lines, whole game), `src/config/gameConfig.ts` (zones/frames/windows), `src/config/levels.ts` (7 arenas). Zero-DOM-UI: HUD/menus are 3D geometry.
- Headless limit (verified): Chromium/SwiftShader renders ~4 rAF frames per `--virtual-time-budget` run → rAF gameplay is unverifiable headless. `?selftest=1|<levelId>` runs scripted full-power throws synchronously and reports via `document.title` + `console`; this is the CI workhorse.
- Dev server: tmux session `axe`, `npm run dev` on `:3002`. Headless binary: `/usr/bin/chromium`.

## 1. Triage (static findings, severity-ranked)
**Confirmed real (read in current code):**
- **D1 — Bounce has no rebound.** `main.ts:1168` zeroes `axeVel`, then `resolveStick → deflect(hitPoint)` (`1118+`) computes rebound from the zeroed vector → bounce hangs at `(±1,0,0)` instead of rebounding. Trigger: ~28% of face hits. Fix: snapshot velocity before zeroing, pass into `deflect`.
- **D2 — Killshot log always lies.** `main.ts:1059` clears `calledKillshot` before the `1061` log ternary → always prints `called-miss`, even on 8-pt hits. Scoring (`1048`) correct. Fix: capture result string before clearing.
- **D3 — Digit1/2/3 aborts live throws.** `main.ts:1252-1254` has no phase/axeState guard; `equipFrame → resetAxeToHand → IDLE` voids in-flight/stuck axes with no miss, skipping recall/end rules. Fix: ignore unless `phase==='play' && axeState==='IDLE'` (menu minis already safe).
- **D4 — KeyR during CHARGING leaks charge state.** `main.ts:1260` flips to `RECALLING` without clearing `charging/charge/overcharge`; recalled-to-IDLE axe renders charged pose and `currentPower()`/trajectory use stale charge. Fix: clear charge fields on R-abort (or route through `resetAxeToHand` + explicit recall accounting).
- **D5 — Esc/lock-loss while CHARGING forces a throw.** `main.ts:1241-1245` calls `releaseAxe()` (succeeds, burns an axe) then pauses. Intent is cancel. Fix: cancel charge without throwing (`charging=false`, back to IDLE), then pause.
- **D6 — KeyQ toggleable mid-flight.** `main.ts:1256-1258` no state guard; flipping after release changes scoring outcome. Fix: only allow when `axeState==='IDLE' || 'CHARGING'` (latch at release).
**Needs runtime evidence (could not decide statically):**
- **D7 — Timer firing mid-flight scores behind resolve screen** (`1332-1338` vs `1340-1346`): code clearly keeps stepping in resolve; need headed repro (release <1s before timeout) to confirm visible desync. Fix if confirmed: freeze axe + defer resolve until axe back to IDLE (or resolve immediately and void in-flight throw — designer call).
- **D8 — Called-killshot miss leaves axe visually STUCK while counting a miss** (`1166-1170` pins position before `resolveStick` knows the outcome). Likely real; confirm headed, fix by deflecting/repositioning on called-miss.
- **D9 — Motion ramp unbounded in endless** (`417-419`: `1+0.2*floor(elapsed/30)`, endless has `time=null`): at 10 min boards slide 5× speed. Confirm feel headed; cap ramp (e.g. max 2×) if approved.
- **By design, do not "fix":** dead `stickThreshold`/`grazeExtraSpeed` (impact speeds 15–32 m/s always pass — rebalance out of scope; instead add `IMPACT_SPEED` debug log so a human can retune later); first-click-eats-lock (browser gesture requirement, document it); vector-lock persistence semantics (designer call).
**False alarm / minor:** stand legs float ~0.6 m (visual only); trajectory cuts at z=-26 vs miss bound -38 (cosmetic); `onNode && points<1` branch dead but harmless; frame-rack hit spheres overlap (nearest-sort mitigates; verify headed).
