🤖 MARIO AI LAB

A deep Q-learning agent that learned to play the first level of Super Mario World from raw pixels — bundled into this app from the mario-ai research project (see ai/LICENSE).

HOW IT LEARNS

  • Watches the game as 32×32 + 64×64 grayscale screenshots, 4 frames of history, every 5th frame.
  • Stores what it sees in a 250k-entry replay memory, then trains on random batches.
  • Epsilon-greedy policy: random moves 80% of the time at first, down to 10% by action 400k.
  • ~6.6M parameters across three branches: action history, screenshot history, current screenshot + spatial transformer.

TRY THE AUTOPILOT DEMO

No GPU needed: a screen-reactive bot that watches whatever you load, like the DQN does — it taps through menus while the picture is still, follows the scroll direction once the world moves — horizontal and vertical, so it climbs and descends with the camera instead of only pushing left/right — holds run while the pixels demand it, and alternates the action buttons on the beat — jump in one game is attack in another — working the L/R shoulders in every fourth beat. Pause, game over, or a black fade goes quiet and it finds its own way back. One brain, every game. It stays on until you toggle it off — your own button presses just join in alongside it. It drives player 2 out of the box while you play player 1 — both at the same time, neither overriding the other — as two cloned copilot brains — same screen, but each with its own rhythm and button order, so player 2 never just parrots player 1. Narrow it in TUNE below. The trained Torch model itself needs CUDA + lsnes — see the project README.

FIGHTER PROFILE: UMK3

From the manual: RUN = hold R + Forward to close distance. BLOCK = hold L. Crouch kick = DOWN + X/A, uppercut = DOWN + Y, spin moves = hold AWAY + kick, jump-ins = UP(+toward) + punch timed on the way down. Fighter select takes any button except START; START picks menus. The UMK3 profile plays exactly this way — approach with RUN, strike flurries (button sequences land kombos), BLOCK phases, crouch uppercuts, jump-ins, and rotating special-motion strings from the full move list (ai/umk3-moves.js: 85 combat moves, 25 fighters — Scorpion's spear, Sub-Zero's slide, Reptile's forceballs, simultaneous chords like Sonya's leg grab). Finishers, hold-charges, air-only moves, morphs and bosses are excluded (unverifiable states). Sides alternate since facing is unknown.

AUTONOMOUS PLAYER LOOP

Every 2s the loop observes (live frame + audio + words), plans a short sequence, acts through the real P1/P2 controllers, then verifies the result on the next frames. Deaths retry via START and, from the 2nd death, the strategic checkpoint. Still-in-play ~20s escalates: reverse burst → checkpoint reload → human help request. It never stops permanently, never edits memory or pixels, and P2 is tracked as an ally, never a target. Pause the AI anytime with its own toggle — your inputs always work alongside it.
