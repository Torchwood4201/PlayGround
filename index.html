    What is this?

    This page was empty — the issue asked to “use the added files to upgrade what is here (Website)”. The two attachments became the whole site:

    1. minecraft-decompiled-0.8-alpha-main.zip — decompiled Minecraft 0.0.8a (“Cave Game”, 2009). Its LevelGen/NoiseMap terrain code, AABB collision, Player/Entity physics and Tile face-shading were ported to JavaScript (js/world.js, js/game.js) for the playable demo, and the sources are browsable under Source. Textures (grass.png, dirt.png, char.png, clouds.png, default.gif) ship in assets/textures/.
    2. Minecraft.sf2 — “Minecraft Note Block Studio 3” SoundFont (Polyphone, 10 note-block instruments). It is fetched, parsed in-page (js/sf2.js) and played with WebAudio — no conversion, no server synthesis. The Music tab is a note-block piano + step sequencer built on its real samples.

    Faithful bits

    • Terrain: diamond-square NoiseMap (quirks included) + worm caves, ported 1:1 to seeded JS so worlds are shareable via seed.
    • Face shading 1.0 / 0.8 / 0.6 exactly like Tile.render(); grass top/side/bottom mapping from GrassTile; bush cross-quads + no collision from Bush.
    • Movement: moveRelative accel 0.1/0.02, gravity 0.08, jump 0.5, friction 0.91/0.98, eye 1.62 — at the original 20 ticks/s.
    • Note range F♯3–F♯5 and the 10 instruments (harp, bass, bell, flute, chime, guitar, xylophone, snare, hat, bass drum) match note blocks.

    Deliberate upgrades

    • Seeded RNG (the original used unseeded new Random() everywhere), WebGL renderer instead of LWJGL display lists, DDA raycast picking instead of glSelectBuffer, localStorage instead of level.dat.
    • Missing terrain.png atlas was rebuilt procedurally around the real grass.png/dirt.png.
