# DOT MATRIX — Wall Ball / 3D

A neon dot-matrix wall-ball game rendered in real time with Three.js.

Break through a luminous wall of signal dots, keep the ball alive, and chain
returns to build your link multiplier. The desktop build supports mouse aiming,
keyboard steering, synthesized arcade audio, pause/resume, persistent high
scores, and escalating wall patterns.

## Play

Serve the project root over HTTP and open `index.html`:

```bash
python3 -m http.server 3002
```

Then visit `http://localhost:3002`. There is no build step, and every runtime
dependency is vendored locally, so the game works fully offline.

## Controls

| Input | Action |
| --- | --- |
| Mouse | Aim the deflector |
| WASD / arrows | Move the deflector |
| Click / Space | Launch the ball |
| P / Escape | Pause or resume |
| M | Mute sound |

The deflector makes a soft auto-assist pass until you first move the mouse or
keyboard, so the opening rally can begin before you take over.
